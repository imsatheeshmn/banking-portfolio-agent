Accepted Architecture Decision Records

All technical and domain decisions are recorded via formal ADRs following the MADR structure, complete with enterprise Oracle bridge notes.

ADR ID Title Status Key Decision
ADR-001 Numeric Precision & Rounding Accepted Quantity NUMERIC(24,8), Price/FX NUMERIC(20,10), Amounts NUMERIC(20,4), ROUND_HALF_UP. Python float banned.
ADR-002 Weighted Average Cost Basis Accepted WAC for Phase A positions; realized P&L recognized at sell execution; FIFO tax lots recorded as extension.
ADR-003 Long-Only Position Policy Accepted Portfolios are strictly long-only. Sells exceeding held inventory trigger validation rejection and quarantine routing.
ADR-004 Multi-Currency & FX Conventions Accepted Mandatory storage of local amount, spot FX rate, rate date, and base currency amount on every transaction ledger row.
ADR-005 Trade Date vs. Settlement Date Accepted Trade Date (T) drives IBOR positions; Settlement Date (T+1) drives cash balances and ABOR reconciliation.
ADR-006 Append-Only Bitemporal Ledger Accepted Zero in-place updates. Reversals and replacements generate linked reversal rows (CANCEL/REPLACEMENT).
ADR-007 Two-Tier Data Quality Framework Accepted In-flight Python/Polars gatekeeper routing to quarantine + dbt generic and singular SQL tests in the warehouse mart.
💡 Oracle / PL/SQL Enterprise Bridge
Unlike Oracle where DDL commits autonomously, PostgreSQL DDL is fully transactional. Every migration runs inside BEGIN ... COMMIT and rolls back completely on any constraint failure. Furthermore, position tables are derived projections computed deterministically from the immutable bitemporal ledger, rather than mutable cache columns maintained by package triggers.

Investment Domain Invariants & Calculation Rules

1. Transaction State Machine

Transactions advance through strict states: NEW → VALIDATED → CONFIRMED → SETTLED. Reversals enter CANCELLED, while failed records are marked REJECTED and routed to quarantine.

2. Net Asset Value (NAV) Formula

NAV = Σ (Quantity_i × Market_Price_i × FX_Rate_i) + Cash_Balance + Accruals - Liabilities

Missing prices produce high-severity valuation exceptions; they are never defaulted silently to $0.00.

3. Reconciliation & Break Management

Reconciliation checks daily positions against simulated custodian extracts and cash against bank statement extracts. Mismatches exceeding tolerances generate breaks tracked through: OPEN → INVESTIGATING → RESOLVED (or WRITTEN_OFF).
